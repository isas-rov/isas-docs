# Sualtı otonomi ve elektrik terimleri

| Terim | Açıklama |
|---|---|
| ROV / AUV | Uzaktan kontrol edilen / otonom su altı aracı |
| DOF | Hareket serbestliği; surge-sway-heave, roll-pitch-yaw |
| Surge / Sway / Heave | İleri–geri / yana / düşey doğrusal hareket |
| Roll / Pitch / Yaw | Boylamasına yatma / burun kalkması / baş yönü dönmesi |
| IMU | İvmeölçer ve jiroskop ölçüm birimi |
| Manyetometre | Manyetik alan vektörü; kalibrasyonla heading'e yardımcı |
| Bar30 | Basınç sensörü; yüzeye göre derinlik tahmini |
| ESC | BLDC motor fazlarını süren elektronik hız kontrolcüsü |
| PWM | Darbe genişliği modülasyonu; servo/ESC arayüzü olabilir |
| MAVLink | Jetson–Pixhawk telemetri/komut protokolü |
| ArduSub | ArduPilot su altı otopilot yazılımı |
| SITL | Otomatik kontrol yazılımını simüle ortamda çalıştırma |
| DVL | Doppler tabanlı su altı hız ölçer (bütçe dışı) |
| Sonar | Su altında akustik algılama cihazı (bütçe dışı) |
| Optical Flow | Kareler arası görüntü özellik hareketi |
| VO | Görüntüden göreli kamera yörüngesi kestirimi |
| VIO | Görüntü+ataletsel ölçüm odometrisi |
| SLAM | Konum kestirimi ve çevre haritalama |
| EKF | Genişletilmiş Kalman filtresi; durum kestirimi |
| PID | Hata üzerinden geri besleme kontrol |
| IBVS | Görüntü hatasından doğrudan kontrol |
| CG / CB | Ağırlık / kaldırma merkezi |
| PDB | Güç dağıtım kartı |
| EMI / EMC | Elektromanyetik girişim / uyumluluk |
| Penetratör | Sızdırmaz hazneden kablo geçiş elemanı |
| Dead reckoning | Son hareketlere dayanarak, dış düzeltmesiz konum kestirimi; drift olur |
| Failsafe | Hata veya tehlikede kontrollü güvenli davranış |
